# 🎵 ESP32 RFID Music Player & Linker

An interactive, low-power RFID music player built for ESP32 microcontrollers (optimized for **ESP32-C3 SuperMini**). 

Scan hardware UIDs on NFC/RFID tags to play MP3 audio files stored on an SD card. Dynamically link new tags to audio files on the fly through an embedded mobile-friendly Web Dashboard without recompiling code!

---

## ✨ Features

* **Hands-Free Operation:** Automatically enters a low-power **Light Sleep** mode (~2mA) when idle. Automatically wakes up instantly when any tag is tapped onto the reader—no physical buttons required.
* **Pure Hardware UID Scanning:** Fast tag detection compatible with standard NTAG213, MIFARE Classic, or phone NFC chips.
* **On-board Web Dashboard:** Built-in Wi-Fi Access Point (`192.168.4.1`) featuring real-time tag scan monitoring, live audio playback controls, and a master volume slider.
* **Dynamic Mapping Persistence:** Saves tag-to-song mappings directly to `/mappings.json` on the SD card.
* **Motor Drive Output:** Automatically toggles a motor or mechanical indicator on `MOTOR_PIN` during playback.
* **I2S Audio Output:** Clean digital audio output using high-quality I2S DAC modules (e.g., MAX98357A / PCM5102).

---

## 🛠️ Hardware Requirements

* **Microcontroller:** ESP32-WROOM32 (or any standard ESP32 / ESP32-S3)
* **RFID Reader:** MFRC522 (SPI)
* **Audio DAC:** MAX98357A I2S Amplifier
* **Storage:** MicroSD Card Module (SPI)
* **Optional:** NPN Transistor / MOSFET for driving a DC Motor

## 🚀 Quick Start Guide

1. Clone this repository to your local computer.
2. Open the project folder in **Arduino IDE**.
3. Go to **Tools > Board > ESP32 Arduino** and select **ESP32 Dev Module**.
4. Set **Flash Size** to **4MB**.
5. Connect your ESP32-WROOM-32 via USB and select the corresponding COM port.
6. Upload the project!

---

## 📚 Software Dependencies

Install the following libraries via the Arduino Library Manager or PlatformIO before uploading:

1. **MFRC522** by *githubnikola* / *mfrc522*
2. **audio-tools** by *pschatzmann* (`https://github.com/pschatzmann/arduino-audio-tools`)
3. **helix** MP3 Codec by *pschatzmann* (`https://github.com/pschatzmann/arduino-libhelix`)

---

## 💾 SD Card Setup

Format your MicroSD card to **FAT32** and create a `/music/` folder at the root:

```text
SD_CARD/
├── mappings.json (Auto-generated by Web UI)
└── music/
    ├── 1.mp3
    ├── song2.mp3
    └── track3.mp3
```

## 🚀 Web linker Guide

1. Connect your phone or laptop to the created Wi-Fi network:
   * **SSID:** `RFID-MusicPlayer`
   * **Password:** `password123`
2. Navigate to `http://192.168.4.1` in your browser to scan tags and link them to your songs!
